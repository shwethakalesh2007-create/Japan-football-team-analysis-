# Samurai Blue Analysis⚽
A Python project that analyzes Japan football data.

## Features
- Search players by position
- Search matches by opponent
- View Japan's match performance
- View goals and results
- View a match goals graph

## Technologies
- Python
- MySQL
- Pandas
- NumPy
- Matplotlib

## How to Use
1. Download the project.
2. Install Python and MySQL.
3. Run the `players.sql` file to create the required player database and data.
4. Install the required Python libraries.
5. Run `japan.py`.
6. Enter your own MySQL password when asked.
7. Enter a player position, such as:
   - Forward
   - Defender
   - Midfielder
   - Goalkeeper
8. Enter an opponent name, such as:
   - Brazil
   - Sweden
   - Tunisia
   - Netherlands

The program will display the matching player or match information and show Japan's performance analysis.

## Note
The project does not contain or share anyone's MySQL password.

Your own MySQL setup is required to run the project.
